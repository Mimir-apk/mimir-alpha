# Alpha Release 1 - Demo

Mimir `0.1.0-alpha.1-demo` (código 7) es un alfa temprano para Android 11 o posterior, con
Mimir Tweaker `0.4.4-tw12` (código 12) opcional.
[Descargar APKs](https://github.com/Mimir-apk/mimir-alpha/releases/tag/v0.1.0-alpha.1-demo) ·
[Instalar o actualizar](instalar.md) · [Problemas conocidos](problemas-conocidos.md)

- Escanea carpetas locales, explora estantes, Favoritos y Tomos, y abre juegos en tus emuladores.
- Usa un mando o la pantalla táctil, administra archivos y escucha música local. Los dispositivos
  compatibles con dos pantallas también tienen estante, actividad, música y trackpad abajo.
- Las funciones en línea son opcionales y requieren tu configuración; no se incluyen credenciales.
  SteamGridDB usa tu propia clave. ScreenScraper e IGDB no están configurados en estos APKs;
  iniciar sesión con una cuenta personal de ScreenScraper no habilita sus descargas.
- Tweaker ofrece controles de hardware solo con chips, firmware y capacidades compatibles.
  Instalarlo no agrega acceso que el firmware no tenga.

No se incluyen juegos, emuladores, BIOS ni firmware. El escaneo local y el lanzamiento funcionan sin conexión.

Usa los dos APK del mismo release. Si quieres Tweaker, instálalo primero y después Mimir.
Tweaker no tiene icono de lanzador; se abre desde Utility en Mimir.

Se conservan los identificadores de paquete y el certificado oficial. Ambos códigos de versión
aumentan respecto de los alfas oficiales anteriores. Instala encima de una copia oficial compatible,
sin desinstalar ni borrar datos, para conservar biblioteca, Tomos y configuración. Las compilaciones
personales o de CI pueden tener otra firma; no desinstales para evitar un error de firma.

Es un alfa de demostración: puede tener errores y variar según dispositivo, firmware y emulador.
No se afirma una nueva validación de hardware, animaciones o rendimiento. Este repositorio público
empieza con una instantánea limpia del código, sin el historial de desarrollo anterior. El código
original es GPL-3.0-or-later; el material de terceros conserva sus condiciones.
