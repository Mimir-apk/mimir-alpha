`SHA256SUMS.txt` lists the exact download hashes. Verify with your system's SHA-256 utility;
with the release payload files in one directory, `sha256sum -c SHA256SUMS.txt` checks the set.
Both APKs retain the official signing-certificate SHA-256 fingerprint:

```text
964a64cf186537819583ce379dc425132e68812e0293108ffcb50dab15cf2df3
```

Use `apksigner verify --print-certs` to inspect a downloaded APK. A file hash identifies the
exact download; the certificate identifies the key used for compatible updates. Both apps have
higher version codes than earlier official Alpha builds. Tweaker 12 updates the displayed source
repository address; its Binder API remains 11.

`SOURCE_MANIFEST.txt` records the release commit and tracked source file hashes.
`THIRD_PARTY_NOTICES.zip` contains licensing and attribution texts from that revision.
