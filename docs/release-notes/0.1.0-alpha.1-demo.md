# Alpha Release 1 - Demo

Mimir `0.1.0-alpha.1-demo` (code 7) is an early alpha for Android 11 or newer, with optional
Mimir Tweaker `0.4.4-tw12` (code 12).
[Download APKs](https://github.com/Mimir-apk/mimir-alpha/releases/tag/v0.1.0-alpha.1-demo) ·
[Install or update](../install.md) · [Known issues](../known-issues.md) ·
[Español](../es/notas-0.1.0-alpha.1-demo.md)

## Try the demo

- Scan your local game folders, browse shelves, Favorites and Tomes, and launch through an installed emulator.
- Use a controller or touch, manage files and play local music. Compatible dual-display handhelds
  also have a lower-screen shelf, activity page, music player and trackpad.
- Add optional online artwork and account features through your own configuration. Provider
  credentials are not bundled. SteamGridDB needs your own key; ScreenScraper and IGDB are
  unconfigured in these APKs, and a personal ScreenScraper login cannot enable their downloads.
- Install the optional Tweaker for hardware controls on supported chips with compatible vendor
  firmware and runtime capabilities. Installing it does not add missing firmware access.

Mimir includes no games, emulators, BIOS files or firmware. Local scanning and launch dispatch work offline.

## Install and update

Use both APKs from this release; install Tweaker first if you want it, then Mimir. The production
Tweaker has no launcher icon; open it from Mimir's Utility panel.

Both APKs keep their existing package IDs and official signing certificate. Their version codes
increase over earlier official Alpha builds. Install over an existing compatible official copy
without uninstalling or clearing data to keep your library, Tomes and settings. Personal and CI
builds can have a different signer; do not uninstall an existing copy to bypass a signature error.
See [release files](0.1.0-alpha.1-demo-files.md) for checksums, signing and source.

## Limits and source

This is a demo alpha. Expect bugs; controller behavior, emulator return and dual-display features
vary by device and firmware. No new device, animation or performance acceptance is claimed.
See [known issues](../known-issues.md) and [Privacy](../../PRIVACY.md).
